# AGENTS.md

## О проекте

«Насколько хорошо ты меня знаешь?» — браузерная викторина на русском языке.
5 вопросов о владельце сайта, режимы «Играть одному» и «Дуэль вдвоём» на одном
телефоне, таймер на 20 секунд, подсказка 50/50, звуки через Web Audio API,
итоговый экран с результатом.

## Файлы

- `index.html` — разметка всех экранов: старт, настройка дуэли, передача телефона, игра, результат.
- `style.css` — все стили и адаптивная вёрстка.
- `script.js` — вся логика игры: вопросы, таймер, счёт, подсказки, звук, экраны.
- `questions.js` — массив `QUESTIONS` с вопросами, вариантами ответов и картинками (данные игры).
- `.claude/launch.json` — конфигурация локального запуска (не часть игры).

## Правила

1. Только HTML, CSS и JS. Никаких внешних библиотек, фреймворков и CDN.
2. Меняй по одному изменению за раз. После правки перечисляй изменённые файлы.
3. Не трогай `questions.js` без явной просьбы.
4. Не делай `git push` без явной команды.
5. Не говори «работает», если не проверил.
6. Счёт игрока никогда не бывает меньше 0.
7. Подсказка 50/50 — не больше 2 раз за игру.
